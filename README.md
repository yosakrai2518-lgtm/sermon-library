# Sermon Library — Starter Project

เว็บแอปต้นแบบสำหรับคลังคำเทศนาและบทเรียนพระคัมภีร์ไทย–อังกฤษ

## มีอะไรในโปรเจกต์นี้
- ค้นหาสินค้าจากชื่อ/ข้อพระคัมภีร์
- กรองตามหมวดหมู่
- เลือกภาษาไทย/English/ไทย-อังกฤษ
- ดูรายละเอียดสินค้า
- บันทึกรายการไว้ในอุปกรณ์ด้วย localStorage
- โครงสร้าง PWA เบื้องต้น (ติดตั้งบนหน้าจอหลักได้เมื่อเผยแพร่ผ่าน HTTPS)

## วิธีเปิดทดลอง
1. แตกไฟล์ ZIP
2. เปิด `index.html` ด้วย Chrome, Safari หรือ Edge
3. ทดลองค้นหา เลือกหมวดหมู่ และเปิดรายละเอียดสินค้า

## ข้อจำกัดสำคัญ
รุ่นนี้เป็น frontend prototype เท่านั้น ยังไม่มี:
- ระบบชำระเงินจริง / PromptPay checkout
- บัญชีผู้ใช้หรือฐานข้อมูลบนเซิร์ฟเวอร์
- ระบบส่งไฟล์ PDF อัตโนมัติ
- ระบบป้องกันการแชร์ไฟล์หรือใบอนุญาตการใช้งาน
- การเผยแพร่บน App Store / Google Play

ปุ่มเตรียมสินค้าเป็นเพียงตัวอย่าง UI ไม่ใช่ระบบสั่งซื้อจริง

## ขั้นตอนถัดไป
1. แทนที่สินค้าและราคาให้เป็นเนื้อหาที่คุณเป็นเจ้าของหรือได้รับอนุญาต
2. สร้าง PDF จริงใน Google Docs/Word แล้วทดสอบอ่านบนมือถือ
3. เผยแพร่เว็บไซต์ผ่าน GitHub Pages หรือ Cloudflare Pages (ต้องมีบัญชีและทำตามขั้นตอนของผู้ให้บริการ)
4. เริ่มรับคำสั่งซื้อแบบ manual หลังระบุช่องทางชำระเงินและเงื่อนไขชัดเจน
5. เมื่อมีลูกค้าจริง ค่อยเพิ่ม backend, order tracking และระบบส่งไฟล์
6. ตรวจสอบค่าธรรมเนียมและกฎของผู้ให้บริการก่อนเปิดรับชำระเงินจริง

## แก้ไขสินค้า
ใน `index.html` ค้นหา `const products=[` แล้วแก้ชื่อสินค้า ภาษาอังกฤษ ข้อพระคัมภีร์ ราคา และรายการเนื้อหา
